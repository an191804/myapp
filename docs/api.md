# API仕様

## POST /api/○○
説明：新しい売り上げデータを追加する

リクエストJSON：
    {
  "date": "2024-05-12",
  "amount": 48000,
  "items": 40
}

レスポンスJSON：
{
  "id": 3,
  "date": "2024-05-12",
  "amount": 48000,
  "items": 40
}

## GET /api/○○
説明：売上データの一覧を返す

レスポンス：
[
  {
    "id": 1,
    "date": "2024-05-10",
    "amount": 52000,
    "items": 45
  },
  {
    "id": 2,
    "date": "2024-05-11",
    "amount": 61000,
    "items": 52
  }
]
